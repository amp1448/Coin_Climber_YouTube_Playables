HOW TO TEST
1. For local preview: from this directory run python -m http.server 8000, then visit http://localhost:8000.
2. For actual YouTube SDK testing, use the official Playables SDK Test Suite and test your uploaded build. Local mode does not validate the YouTube environment.
3. Test mobile touch, mouse, keyboard, pause/resume, game over, high-score cloud saving and score reporting.

HOW TO SUBMIT
1. Apply for YouTube Playables developer access.
2. If invited and onboarded, sign into YouTube Playables Developer Portal as a channel manager.
3. Upload the ZIP and select index.html as entry point.
4. Add game metadata, required thumbnails, test through the portal, complete the review process.

NOTE
This is a candidate build, NOT certified or approved by YouTube. Approval and publication require YouTube access, verification, testing and review.

Official docs: https://developers.google.com/youtube/gaming/playables
